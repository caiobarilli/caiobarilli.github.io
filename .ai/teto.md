# Teto

Portfólio estático no GitHub Pages.

- Só HTML, CSS, JS e imagens gerados no build (`output: "export"`). Sem servidor, sem API, sem banco.
- Sem formulário, sem cookie, sem analytics. Contato é por link (e-mail, LinkedIn, GitHub).
- Cache e cabeçalhos HTTP são os do Pages; não dá para configurar.

Fora do teto até o Maintainer mandar:

- coletar dado de visitante
- serviço externo chamado do navegador
- domínio próprio
